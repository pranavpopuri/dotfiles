One-command setup — macOS or Linux:

  sh -c "$(curl -fsLS get.chezmoi.io)" -- -b ~/bin init --apply pranavpopuri

This installs chezmoi to ~/bin, clones the dotfiles, applies them, and then
chezmoi's run scripts install everything else automatically:

  - macOS: installs Homebrew if missing, then `brew bundle` from Brewfile.core,
    and applies macos.sh system defaults once (prompts for sudo; restarts
    Dock/Finder).
  - Linux: fetches the tools into ~/bin with eget — no root, no hardcoded
    URLs/versions (install-tools-linux.sh; works on x86_64 and aarch64).
    Node comes from fnm, which resolves the LTS release at install time.

On Linux, Helix builds its tree-sitter grammars (the MIPS one included) on
demand, which needs git and a C compiler. Install those, then run
':grammar fetch' and ':grammar build' inside Helix.

When it finishes, restart your shell:  exec $SHELL
